# The Yellow Halls

3D first-person horror game (Three.js) with co-op rooms.

## Run locally
    node server.js
Open http://localhost:3000

## Deploy on Render
1. Push this folder to GitHub.
2. Render -> New -> **Web Service** -> pick the repo.
3. Build command: `npm install` (or leave empty). Start command: `npm start`.
4. Open the URL Render gives you. Press PLAY to get a room code; friends use JOIN FRIEND.

Note: free Render services sleep when idle, the first load can take ~30 seconds.
